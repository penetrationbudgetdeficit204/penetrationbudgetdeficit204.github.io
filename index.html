🚀 What Is hyper-hand?

hyper-hand is a bridge between artificial intelligence agents and Windows virtual machines running on Hyper-V. Normally, an AI assistant can only talk — it can write text back to you, but it cannot see your screen, click a button, or open a program. hyper-hand changes that.

Once it is connected, your AI agent can look at the virtual machine, understand what is on screen, and act on it. It can move the mouse, press keys, launch applications, run commands, copy files in and out, and take a snapshot of the machine so you can rewind if something goes wrong.

The best part is how little setup it needs. There is nothing to install inside the virtual machine itself, no shared folders to configure, no network bridge to build, and no password to type. hyper-hand works at the level of the virtual machine host, so the guest system does not even need to be reachable from the network.

✨ Key Capabilities

📸 Screenshots

The agent can capture the current state of the virtual machine screen at any moment, so it always knows exactly what the user or the system is seeing.

🖱️ Mouse Control

Move the pointer, click, double-click, right-click and drag. Every normal mouse action is available to the agent, just as if a person were sitting at the keyboard.

⌨️ Keyboard Input

Type text, press single keys, and send key combinations such as shortcuts for copying, pasting, closing windows or switching applications.

💻 Command Execution

Run commands inside the guest Windows system and read back the results, so the agent can automate tasks that are faster to do from a prompt.

📁 File Transfer

Send files into the virtual machine and pull files out of it, making it easy to hand documents, scripts or installers to the guest system.

🔖 Checkpoints

Create a restore point before a risky operation and roll back to it afterwards. Experiments stay safe and repeatable.

🧭 Getting Started

You do not need to know how to program to get running. Follow these steps in order and you will be connected in a few minutes.

  1. Open the download page. Visit the releases link above. It lists every published version of hyper-hand.
  2. Pick the newest release. The most recent entry at the top is the one you want. Older entries are kept for reference only.
  3. Grab the Windows file. On the release entry, find the file listed under its assets and save it to a folder you can easily find again, such as your Downloads folder.
  4. Make sure Hyper-V is ready. Open Start, type Hyper-V Manager, and confirm that your Windows virtual machine is listed and currently running. hyper-hand talks to the virtual machine through Hyper-V, so the machine should be started before you connect.
  5. Start hyper-hand. Open the file you downloaded. If Windows shows a security prompt asking whether you want to run it, choose the option that lets it continue.
  6. Choose your virtual machine. hyper-hand shows the Hyper-V machines it can see on your computer. Select the Windows machine you want the agent to work with.
  7. Connect your AI agent. hyper-hand presents itself as an MCP server, which is the standard way AI tools discover new abilities. Point your agent at it and it will immediately see the available actions.

🔌 Connecting an AI Agent

hyper-hand speaks the Model Context Protocol, so any MCP-capable client can use it. That includes Claude Code, Codex, and many other agent tools. The connection is local: your agent runs on the same computer as hyper-hand, and the two talk directly to each other.

In practice, the process looks like this:

  • Start hyper-hand and leave it running in the background.
  • Open your AI agent's settings and add a new MCP server entry.
  • Point that entry at the hyper-hand connection details that the app displays on screen.
  • Restart or refresh your agent so it picks up the new server.
  • Ask the agent a simple question such as "what is on the virtual machine screen right now?" to confirm everything works.

If your agent does not see the new abilities, close and reopen the agent, then check that hyper-hand is still running. Most connection problems are simply one of the two programs not being started.

🖥️ A Typical Session

Here is what using hyper-hand actually feels like. You open your AI agent and describe a goal in plain language, for example: "Open the settings app in the Windows virtual machine and turn off notifications." The agent takes a screenshot to see the desktop, moves the mouse to the Start button, clicks it, types the name of the app, presses Enter, waits a moment, takes another screenshot, and continues from there.

Before it starts changing anything, a careful agent will create a checkpoint. If the result is not what you wanted, you can roll the virtual machine back to the exact moment before the work began. Nothing is lost, and you can try a different instruction.

For longer jobs, the agent can also drop files into the machine — a document to edit, an installer to run, a spreadsheet to fill in — and then copy the finished result back out to your real computer.

🔒 Safety and No Passwords

hyper-hand is built around a simple idea: the virtual machine is a sandbox, and the agent should stay inside it. Because control happens through the Hyper-V layer rather than through a login inside the guest system, you never have to share a Windows password with an AI tool, and you never have to open a network port for it.

  • No password sharing. Your guest account credentials stay private.
  • No guest network required. The virtual machine does not need to be reachable from anywhere.
  • Reversible actions. Checkpoints let you undo a session in seconds.
  • Contained by design. The agent works inside the virtual machine, not on your everyday desktop.

As with any automation, it is wise to keep a checkpoint from before the agent starts and to review what it did afterwards. Treat the virtual machine as a workspace that can always be reset.

📝 Tips for a Smooth First Run

  • Keep the virtual machine window open while the agent works. Watching along makes it obvious what the agent is doing and where it might get stuck.
  • Start with a simple request. A single click or a screenshot confirms the connection before you ask for something long.
  • Give the agent a moment to settle. Screenshots taken immediately after a click can catch the system mid-transition.
  • Create a checkpoint before any instruction that installs software or changes settings.
  • Use clear, concrete wording. "Click the Start button" works better than "do something with the menu".
  • If the agent seems confused, ask it to take a fresh screenshot and describe what it sees. That resets its view of the screen.

❓ Frequently Asked Questions

Do I need to be a programmer?

No. Downloading and starting hyper-hand is a normal Windows application workflow. The only technical step is adding the connection entry to your AI agent, and most agents describe this clearly in their own settings screens.

Do I have to install anything inside the virtual machine?

No. hyper-hand works from the host side. The guest Windows system does not need an extra program, an open port or a shared folder.

Will my virtual machine's password be shared?

No. hyper-hand does not need guest credentials. Control happens through Hyper-V rather than through a login inside the machine, so your password stays with you.

Can I undo what the agent did?

Yes, if you made a checkpoint first. Restoring a checkpoint returns the virtual machine to the exact state it was in when the checkpoint was created.

Which AI agents work with it?

Any client that supports the Model Context Protocol. Claude Code and Codex are two common examples, and the list keeps growing as more tools adopt the standard.

Where do I get updates?

🛠️ Troubleshooting

My virtual machine does not appear in the list

Open Hyper-V Manager and confirm the machine exists and is running. Machines that are stopped or that belong to a different Hyper-V setup will not show up.

My agent cannot find hyper-hand

Check that hyper-hand is still running, then reopen your agent's settings and confirm the server entry matches the connection details shown by hyper-hand. Restarting the agent after any change is the quickest fix.

The agent clicks but nothing happens

Ask the agent to take a screenshot first. If the screen has changed since its last look, its clicks may be landing in the wrong place. A fresh screenshot corrects the position.

The download will not open

Check the file finished downloading before opening it, and make sure you saved it somewhere you have permission to run programs, such as your Downloads folder rather than a temporary location.
